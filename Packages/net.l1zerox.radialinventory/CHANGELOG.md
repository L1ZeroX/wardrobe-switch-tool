# 1.13.0

- 実験機能「胸・衣装補正」を追加。素体の胸シェイプキーを0〜100で調整し、プレビュー上で衣装をなぞって貫通を補正できます。
- 「貫通を直す」「押し出す」「元へ戻す」のブラシ、大きさ・強さ・肌との隙間、ストロークの取り消し／やり直し、補正前後の比較に対応します。
- 適用までは一時複製だけを変更。適用時は別のメッシュアセットを作成し、元メッシュを保持します。「適用済み・復元」でON/OFFできます。
- Unity上で体型を決めるための静的な補正です。VRChat内のサイズ変更への自動追従、動作中の貫通保証、他アバターへの衣装変換は含みません。

# 1.12.0

- body_allとbody_baseを同じ優先度で自動検出。名前が異なる素体も候補にし、登録済み衣装のメッシュを自動候補から除外します。手動指定ではメッシュとシェイプキーを一覧で選べます。
