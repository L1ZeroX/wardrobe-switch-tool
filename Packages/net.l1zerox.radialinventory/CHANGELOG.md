# 1.8.0

- グループごとの着脱状態を記憶。他の衣装から戻ると個別に脱いだ状態を復元します。Expressionsから記憶ON/OFFを変更できます。
- グループへ衣装の親オブジェクトを入れると、配下のメッシュをプロップへ自動登録。
- big_breast / small_breastなど名前で判定できる選択肢だけ選択画面を表示。通常パーツは自動登録します。

- 着脱の記憶はアバター再読み込みまで有効。元の衣装オブジェクトは削除・表示変更しません。
