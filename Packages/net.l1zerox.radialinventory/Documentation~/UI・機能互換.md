# 1.1.0 UI・機能互換

メイン画面は **衣装簡単切替ツール → エディター** です。従来の **Radial Inventory → RISV4 Editor** からも同じ画面を開けます。

オリジナルのヘッダー、対象アバター選択、設定の書き出し／読み戻し、3モード、Write Defaults、容量表示、適用／解除を維持しました。画面の最小サイズは960×620です。

| モード／機能 | 対応 |
|---|---|
| シンプル | 人体図からの部位選択、衣装セット、対象オブジェクト、初期表示、排他設定を元のタブで編集 |
| ベーシック | グループ→項目→設定の3列、グループ排他、リセット、ローカル限定、状態保存、対象指定を維持 |
| アドバンス | 既存メニューの合流、排他グループ、追加ON/OFFアニメーション、排他解除時アニメーション、タイマー、パラメーター操作、複数対象、マテリアル指定を維持 |
| 設定／移行 | 元の設定画面、V3移行コード、JSON入出力を維持。排他解除時アニメーションのJSON保存・読み戻しを補修 |
| 画像 | 元のアイコン指定欄の近くに撮影・撮り直しを追加。構図調整は補助ツール |
| 補助機能 | 検索・一括登録・移行・バックアップは上部ツールバーから開く |

3モードの `BuildFXLayer` を原作者版4.6.0と比較し、生成ロジックが同一であることを確認しました。比較で除外した差は、null参照への防御と、削除するパラメーターを本ツールの接頭辞へ限定する修正だけです。証跡は `検証用/FX互換比較.json` にあります。

追加修正：

- シンプルのメニュー表示を元の部位名・衣装セット名へ戻し、空グループを非表示にしました。
- 既存メニューの合流は元と同じアドバンスモードに限定しました。
- ベーシックの初期値はグループの排他モードから計算します。グループを並べ替え・削除しても排他モードと既定クリップを追従させます。
- 解除時はページ分割先の入口も除去し、容量超過時も解除できます。解除したものをビルド時に自動復元しません。再度「適用」すると復帰します。

ページ分割、GUID保持、容量超過の事前検査、バックアップ付き移行は継続します。メニューやパラメーターの生成はこの不具合修正を含むため、原作の不具合まで同じ動作に戻すものではありません。

原作の全設定項目とFX生成処理を維持していますが、全組み合わせのVRChat実機挙動を保証する検証は行っていません。SDK最終バンドル生成・VRChat実機表示は引き続き未確認です。

検証：Unity 37項目＋再起動2項目に合格。ログは `検証用/UI互換検証/KaiVerification.txt`、移行ランチャーは4項目に合格しています。
