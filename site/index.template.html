できること

衣装に合わせて、
使いやすい切り替え方を。

01 / プレビューと合体

まとめて着たいパーツを、
ひとつのスイッチに。

複数のプロップを合体して、一度にON/OFF。あとから「分離する」で個別のプロップに戻せます。

  • 合体するパーツを画像で確認
  • 「衣装だけ／アバター全体」を切り替え
  • 小・中・大の表示サイズ、向き・ズームを調整
02 / 衣装の自動登録

いつものパーツは自動で。
サイズ違いは、自分で選ぶ。

衣装をグループへ追加すると、パーツを見つけてプロップへ登録。インナーのサイズ違いなど、選択が必要な候補は確認画面から選べます。

候補の判定は名前をもとに行います。衣装の構成に合わせて、登録するパーツを確認できます。

着替え

個別にも、まとめても。

Expressionsメニューからパーツの着脱とグループ単位の着替えを操作。他の衣装を自動でOFFにする設定も使えます。

記憶

脱いだ状態を、覚えておく。

他の衣装から戻っても、個別に脱いだ状態を復元。記憶のON/OFFも選べます。記憶はアバターの再読み込みまで有効です。

画像

メニューでも、見て選ぶ。

衣装だけの透過サムネイルと、グループごとの全身画像をPNGで作成。Expressionsメニューのアイコンにも反映できます。

実験機能

靴の着脱に、ヒール補正を連動。

Shoesを含む衣装とヒール用ブレンドシェイプを自動検出。履いたときの値は0〜100、脱いだときは0。手動指定・OFFにも対応します。初期状態はOFFです。

ボタンでVCCが開かない場合

VCCの Settings → Packages → Add Repository に、次のURLを貼り付けてください。

導入前に確認

  • Unity 2022.3 / VRChat Avatars SDK 3.10.3以上・3.11.0未満が対象です。
  • Radial Inventory System V4の改変版です。元のVPMパッケージを置き換えます。移行前にプロジェクトをバックアップしてください。
  • Assets内に旧版のスクリプトを入れている場合は、併用する前に導入手順を確認してください。
