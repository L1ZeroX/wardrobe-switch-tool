衣装簡単切替ツール

衣装を個別に、またはグループごとに切り替え。衣装の透過サムネイルと、着替えた全身画像をExpressionsメニューへ。

VCCに追加

VCCで追加を確認し、対象プロジェクトの「Manage Project」から本ツールをインストールしてください。

ボタンで開かない場合

VCCの Settings → Packages → Add Repository に、次のURLを貼り付けます。

{{LISTING_URL}}

初めて使う方へ

  • Unity 2022.3、VRChat Avatars SDK 3.10.3以上・3.11.0未満が対象です。
  • Unityの「衣装簡単切替ツール → エディター」から開きます。
  • Radial Inventory System V4の改変版です。元のVPMパッケージを置き換えます。移行前にプロジェクトをバックアップしてください。
  • Assets内に旧版のスクリプトを入れている場合は、そのまま併用せず、下の導入手順を確認してください。
